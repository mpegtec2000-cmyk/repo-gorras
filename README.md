# SPM Streetwear — E-Commerce Web App

Sitio web e-commerce oficial de **SPM® Streetwear**, marca chilena de gorras y accesorios de alta calidad (Snapback, Curved, Trucker, Fitted, Beanies).

## 🚀 Tecnologías

- **Next.js 16** (App Router & Turbopack)
- **React 19** & TypeScript
- **Lucide React** (iconografía)
- **CSS Modules** con diseño responsivo, estética streetwear oscura y animaciones

## 🛠️ Instalación y Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
